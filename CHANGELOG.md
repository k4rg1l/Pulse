# Changelog

All notable changes to Pulse are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0] - 2026-11-01

### Added

- Audio tab: switch output and input devices, set master and microphone volume, and mute the microphone.
- Per-app volume and mute, with each app's name and icon.
- Now playing: track, artist, album art, timeline and playback controls for apps that report to Windows.
- Live lines that follow each app's sound on Windows 11, coloured from each app's icon or album art.
- Tabs in Settings: choose which tabs show and their order. A hidden tab's source stops running.

### Changed

- Dropdowns open over the panel and no longer move the layout.
- Pulse loads the Audio tab the first time it is opened.
- Keep Pulse ready is listed at about 120 MB more memory, corrected from 250 MB.
- The tray stat moves to the first shown tab if its own tab is hidden.

## [0.2.1] - 2026-10-31

### Fixed

- Updates download from normal release links, so they work on shared networks.

## [0.2.0] - 2026-10-31

### Added

- One-click updates. Pulse shows a card when a new version is available, and installs it when you click Update.

### Fixed

- Pulse opens on the tab chosen in Open to, not the last tab you used.

## [0.1.1] - 2026-10-31

### Changed

- New app icon and installer icon.

## [0.1.0] - 2026-10-31

### Added

- First public release: System Resources, Claude and Codex tabs in a Windows tray panel.
